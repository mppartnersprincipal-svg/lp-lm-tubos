# UI kit — Site institucional LM Tubos

Três telas click-through (Header/Footer compartilhados): **Home** (hero com fachada real, linhas de produto, ranhurado em destaque, como funciona, CTA), **Produtos** (catálogo por abas, filtro "somente pronta entrega", sem preço — modelo de orçamento) e **Contato** (formulário de lista de materiais + WhatsApp + endereço).

Arquivos: `index.html` (roteador), `Header.jsx`, `Footer.jsx`, `Home.jsx`, `Produtos.jsx`, `Contato.jsx`. As telas consomem os componentes de `components/` via o namespace `NS`.

Fotos de produto são placeholders cinza: substituir por fotografia real do estoque.
