Botão de ação em pílula: primário vermelho para CTA comercial, secundário azul-marinho, WhatsApp verde para contato. Hover eleva 2px com sombra colorida; press encolhe 2%.

```jsx
<Button variant="primary" size="lg" arrow>Pedir orçamento</Button>
<Button variant="whatsapp" href="https://wa.me/…">WhatsApp</Button>
<Button loading>Enviando</Button>
```

Variantes: primary, secondary, outline, ghost, whatsapp, inverse. Tamanhos sm 36 / md 44 / lg 52. `arrow` adiciona seta animada (só em CTAs que levam a outra tela). Máximo 1 primary por bloco visível (hierarquia).
